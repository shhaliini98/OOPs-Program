#Number Converter

A simple C++ console-based application that converts numbers between different number systems.

This project was created as a beginner-level C++ project to practice programming fundamentals and understand how different number systems work.

# Features
🔄 Convert Decimal to Binary
🔄 Convert Binary to Decimal
🔄 Convert Decimal to Octal
🔄 Convert Octal to Decimal
🔄 Convert Decimal to Hexadecimal
🔄 Convert Hexadecimal to Decimal
📋 Simple menu-driven interface
💻 Runs directly in the terminal/console
🔢 Number Conversions Supported
Conversion	Example
Decimal → Binary	10 → 1010
Binary → Decimal	1010 → 10
Decimal → Octal	10 → 12
Octal → Decimal	12 → 10
Decimal → Hexadecimal	255 → FF
Hexadecimal → Decimal	FF → 255

⚙️ How the Program Works

When the program starts, it displays a menu containing different conversion options.

The user selects the required conversion and enters a number.

The program then performs the required conversion and displays the result.
